# Python Coursework — Semester 3

This repository contains Python practical assignments completed as part of my coursework.

## Topics Covered

- **PRACTICAL 1 — Foundational Python Concepts:** Printing output, comments, basic data types, type conversion, arithmetic operations, and time conversion.
- **PRACTICAL 2 — Lists:** Creating lists, accessing elements, adding items, and performing list operations.
- **PRACTICAL 3 — Dictionaries and Tuples:** Creating and updating dictionaries, storing data, tuple operations, sorting, minimum and maximum values, and tuple immutability.
- **PRACTICAL 4 — Conditions and Loops:** Conditional statements, logical operators, `for` and `while` loops, even/odd checking, palindrome checking, sum of digits, and list processing.
- **PRACTICAL 5 — Exception Handling:** Handling errors using `try` and `except`, including `ZeroDivisionError`, `ValueError`, and general exceptions.
- **PRACTICAL 6 — Object-Oriented Programming and Problem Solving:** Inheritance, `super()`, anagram checking, Armstrong numbers, classes and objects, and vehicle inventory management.
- **PRACTICAL 7 — Object-Oriented Programming:** Magic methods (`__init__` and `__repr__`), inheritance, polymorphism, and encapsulation.

## Tools Used

- **Python** — Programming language used to implement the practical assignments.
- **Jupyter Notebook** — Environment used to write and organize Python code in notebook files (`.ipynb`).
